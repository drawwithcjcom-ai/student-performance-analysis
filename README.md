You are given a dataset of students, their subjects, and marks. The dataset is stored in a list of tuples, where each tuple contains (student_name, subject, marks).

Your tasks are:

1.Convert this dataset into a dictionary where each student is a key, and the value is another dictionary containing subjects as keys and marks as values. 

2.Print each student’s subjects and marks in a neat format.

3.Create a list of students who scored above 80 in any subject.

4.Create another list of students who scored below 40 in any subject.

5.Print the highest scorer per subject.

6.Print the average marks per student.

7.Finally, print the overall topper (student with the highest average).
