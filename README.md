# 📊 Student Performance Analyzer

A simple Python project that analyzes student marks, calculates averages, identifies top performers, and generates a performance summary.

---

## 🚀 Features

* Store student records using Python data structures
* Display subject-wise marks for each student
* Identify students scoring above 80 marks
* Detect students scoring below 40 marks
* Find the highest scorer in each subject
* Calculate total marks and average percentage
* Determine the overall class topper
